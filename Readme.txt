Original Image Sizes Notice
We have uploaded the original images in their various sizes as part of this dataset. These original images represent the unaltered and unique dimensions that were initially captured. Researchers and practitioners who wish to utilize this dataset should be aware that the original images may be necessary if there is a need to return masks/labels to their corresponding original shapes and sizes. This approach ensures the preservation of the anatomical integrity of the images and allows for more precise alignment with the original data. We encourage users to consult the original images for applications requiring precise spatial correspondence or when the preservation of the original aspect ratio is paramount. The inclusion of these original images aligns with best practices in medical imaging and provides additional flexibility for various research and clinical applications.
